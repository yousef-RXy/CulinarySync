# CulinarySync

**A high-performance, framework-less recipe and ingredient management dashboard.**

Built as a custom digital solution for a culinary client, this application demonstrates advanced frontend architecture and state management without relying on heavy frameworks like React or Vue. 

### Technical Architecture
- **Vanilla JavaScript (ES6+):** Pure JS implementation for maximum performance and minimal bundle size.
- **MVC Pattern:** Strict Model-View-Controller architecture for clean separation of concerns and maintainable code.
- **Publisher-Subscriber Pattern:** Custom event handling architecture to manage complex UI state changes smoothly.
- **SASS/SCSS:** Modular styling using the 7-1 architecture pattern.
- **Fractional Math & Data Parsing:** Custom algorithms to dynamically scale recipe servings and fractional ingredient amounts.

### Features
- Real-time recipe search and filtering.
- Dynamic serving adjustment algorithms.
- Local storage integration for saving bookmarks.
- Custom user-uploaded recipe pipeline.
